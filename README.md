# SafePulse

Simple Progressive Web App for quick SOS alerts, location sharing, and automatic check-in timers.

Built for personal safety (especially useful for NYSC corps members and anyone travelling in Nigeria).

## Live Demo

After enabling GitHub Pages: **https://min-seo24.github.io/safepulse/**

## Features

- Large red SOS button
- GPS location + Google Maps link
- Up to 5 emergency contacts (device-only storage)
- One-tap WhatsApp / native share
- **Check-in / Travelling Timer** (auto SOS on expiry)
- Nigerian phone number formatting for WhatsApp
- Installable PWA + basic offline support

## How to Use

1. Open the live link in Chrome on Android.
2. Allow location permission.
3. Add at least one emergency contact.
4. Press SOS or start a check-in timer.

## Important

This does **not** replace calling the police on **112**.

Location is only accessed when you use SOS, timer, or Share. Everything stays on your device.

Stay safe.
